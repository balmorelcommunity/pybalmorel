pybalmorel.plotting.production_profile.plot_profile(MainResults, commodity: str, year: int, scenario: str | int = 0, columns: str = 'Technology', region: str = 'ALL', style: str = 'light', seasons: str | list[str] | None = None, terms: str | list[str] | None = None, price_aggregation: str = 'load-weighted') → Tuple[matplotlib.figure.Figure, matplotlib.axes.Axes]

Plots the production profile of a commodity, in a year, for a certain scenario

By default the whole year is plotted. Use seasons and/or terms to plot only part of it, e.g. seasons=’S02’ plots the second week in a model with weekly seasons.

Args:

MainResults (_type_): The MainResults class containing results commodity (str): The commodity (Electricity, Heat or Hydrogen) year (int): The model year to plot scenario (str, optional): Defaults to the first scenario in MainResults. columns (str, optional): Technology or Fuel as . Defaults to ‘Technology’. region (str, optional): Which country, region or area to plot. Defaults to ‘ALL’. style (str, optional): Plot style, light or dark. Defaults to ‘light’. seasons (str | list[str] | None, optional): Season(s) to plot, e.g. ‘S02’ or [‘S02’, ‘S03’]. Defaults to None, which plots all seasons. terms (str | list[str] | None, optional): Term(s) to plot within the chosen seasons, e.g. [‘T001’, ‘T002’]. Defaults to None, which plots all terms. price_aggregation (str, optional): How to aggregate the price when the plotted region contains several regions (areas for heat). ‘load-weighted’ weights the price of each region by its demand in each timeslice, ‘average’ takes the simple mean. Defaults to ‘load-weighted’.

Returns:

Figure, Axes: The figure and axes objects for further manipulations

Plots the production profile of a commodity, in a year, for a certain scenario, split into one figure per chunk_size timeslices

Use seasons and/or terms to only plot part of the year, e.g. seasons=[‘S02’, ‘S03’] with chunk_size=168 gives one figure for each of those two weeks in a model with weekly seasons of 168 terms.

Args:

MainResults (_type_): The MainResults class containing results commodity (str): The commodity (Electricity, Heat or Hydrogen) year (int): The model year to plot scenario (str, optional): Defaults to the first scenario in MainResults. chunk_size (int, optional): How many timeslices per profile, defaults to 168 columns (str, optional): Technology or Fuel as . Defaults to ‘Technology’. region (str, optional): Which country, region or area to plot. Defaults to ‘ALL’. style (str, optional): Plot style, light or dark. Defaults to ‘light’. seasons (str | list[str] | None, optional): Season(s) to plot, e.g. ‘S02’ or [‘S02’, ‘S03’]. Defaults to None, which plots all seasons. terms (str | list[str] | None, optional): Term(s) to plot within the chosen seasons, e.g. [‘T001’, ‘T002’]. Defaults to None, which plots all terms. price_aggregation (str, optional): How to aggregate the price when the plotted region contains several regions (areas for heat). ‘load-weighted’ weights the price of each region by its demand in each timeslice, ‘average’ takes the simple mean. Defaults to ‘load-weighted’.

Returns:

list[Figure], list[Axes]: The figure and axes objects for further manipulations

pybalmorel.plotting.production_profile._aggregate_price(prices: pandas.DataFrame, demand: pandas.DataFrame, node: str, price_aggregation: str) → pandas.DataFrame

Aggregate the prices of several regions or areas to one price per timeslice.

Args:
prices (pd.DataFrame): Price per node and timeslice, in columns node,

‘SSS’, ‘TTT’ and ‘Val’.

demand (pd.DataFrame): Demand per node and timeslice, in columns node,

‘SSS’, ‘TTT’ and ‘Val’. Several rows per node and timeslice, e.g. one per demand category, are summed.

node (str): The column with the nodes, ‘RRR’ for regions or ‘AAA’ for areas. price_aggregation (str): ‘load-weighted’ weights the price of each node by

its demand, ‘average’ takes the simple mean over the nodes. Timeslices without any demand get the simple mean.

Returns:

pd.DataFrame: The price, indexed by (season, term), in column ‘Val’.

pybalmorel.backcasting.__main__.transmission_max_flow(balmorel_scenario_path, entsoe_data_path, year)

Write XKFX_ENTSOE.inc: backcast transmission overrides from ENTSO-E Observed Max Flow.

Reads the scenario’s current XKFX borders, fetches matching ENTSO-E cross-border flows for YEAR, and writes/updates <balmorel-scenario-path>/data/XKFX_ENTSOE.inc plus the $include in XKFX.inc. See CONTEXT.md and docs/adr/0005, 0006.

pybalmorel.backcasting.__main__.ttf_csv(html_path, historicalprices_path)

Split a saved Yahoo Finance TTF=F history page into natural_gas_TTF_<year>.csv.

HTML_PATH is the page https://finance.yahoo.com/quote/TTF%3DF/history/ saved from a browser, covering any number of years. One CSV per year is written to HISTORICALPRICES_PATH in the format the fuelprices command reads.

pybalmorel.backcasting.__main__.fuelprices(balmorel_scenario_path, historicalprices_path, year)

Write FUELPRICE.inc + FUELPRICE_CONSTANT.inc: (S,T)-resolved historical NATGAS/COAL prices for backcasting.

Reads HISTORICALPRICES_PATH’s CSVs, converts them to the Price Year (EUR2016, bundled HICP and EUR/USD tables), maps them onto the UTC Backcast Calendar and writes <balmorel-scenario-path>/data/FUELPRICE.inc and FUELPRICE_CONSTANT.inc. See docs/adr/0001-fuelprice-season-term-resolution.md in the Balmorel repo. Warns if balopt.opt doesn’t set FUELPRICE_DOL=YYY_AAA_FFF_SSS_TTT (it is never edited).

pybalmorel.backcasting.__main__.co2_tax(balmorel_scenario_path, historicalprices_path, year, co2_overrides)

Write TAX_CO2_ST.inc: (S,T)-resolved historical CO2 tax for backcasting.

Reads the EEX EUA primary-auction report for YEAR under HISTORICALPRICES_PATH, converts it to the Price Year (EUR2016), maps it onto the UTC Backcast Calendar and writes <balmorel-scenario-path>/data/TAX_CO2_ST.inc. See docs/adr/0002-co2-tax-season-term-resolution.md in the Balmorel repo. Warns if balopt.opt doesn’t set TAX_CO2_DOL=YYY_CCC_SSS_TTT (it is never edited).

pybalmorel.backcasting.scenariochecks

Scenario Checks

Read-only checks that a Balmorel backcast scenario will actually use the inputs pybalmorel generates for it. Nothing here edits the scenario - it only warns (see docs/adr/0006: pybalmorel writes data files, never options).

Created on 15.10.2026 @author: Mathias Berg Rosendal

PostDoc at DTU Management (Energy Economics & Modelling)

pybalmorel.backcasting.scenariochecks.check_hardcoded_fuelprices(balmorel_scenario_path: str | pathlib.Path, fuels: list[str], file_name: str = 'HYDROGEN_FUELPRICE.inc') → list[str]

Warn about uncommented lines in an include file that name any of fuels.

HYDROGEN_FUELPRICE.inc assigns FUELPRICE_HYDROGEN, which overrides IFUELPRICE wherever it is nonzero - a hardcoded COAL or NATGAS price there silently replaces the generated FUELPRICE.inc.

Args:

balmorel_scenario_path (str | Path): The scenario folder. fuels (list[str]): FFF fuel names to look for, e.g. [‘NATGAS’, ‘COAL’]. file_name (str, optional): The include to check. Defaults to ‘HYDROGEN_FUELPRICE.inc’.

Returns:

list[str]: The offending lines (stripped).

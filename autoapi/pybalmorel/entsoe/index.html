pybalmorel.entsoe

ENTSO-E API

Generic client for fetching data from the ENTSO-E transparency platform, including the zone-code vocabulary bridging ENTSO-E bidding zones and Balmorel regions (see CONTEXT.md). Independent of Balmorel backcasting - see pybalmorel.backcasting for that.

TODO: consider a standalone CLI here (e.g. python -m pybalmorel.entsoe) for downloading raw ENTSO-E data scoped to Balmorel bidding zones, separate from the backcasting validation workflow.

pybalmorel.entsoe.zone_eic_code(zone: str) → str

The EIC code of any ENTSO-E zone identifier.

Accepts a Balmorel/canonical region name (‘DK1’, ‘UK’), an entsoe-py area name (‘DK_1’, ‘GB’) or an EIC code (‘10YDK-1——–W’), so files fetched under different spellings of the same zone can be recognised as one.

Args:

zone (str): The zone identifier.

Returns:

str: The EIC code, or the query code itself if entsoe-py doesn’t know it.

pybalmorel.entsoe.zone_to_region(zone: str) → str

The region name of any ENTSO-E zone identifier (before canonical translation).

Like entsoe_code_to_region, but also understands entsoe-py area names (‘DK_1’ -> ‘DK1’, ‘IT_NORD’ -> ‘IT-NORD’, ‘GB’ -> ‘UK’) and EIC codes not in bidding_zone_codes.

Args:

zone (str): The zone identifier.

Returns:

str: The region name, falling back to the entsoe-py area name or zone itself.

pybalmorel.entsoe.transmission_files(path: str | pathlib.Path, year: int, entsoe_query: str = 'crossborder_flows') → dict[tuple[str, str], pathlib.Path]

The fetched transmission files in path, one per directed pair of EIC codes.

A pair fetched under several spellings (e.g. ‘DK_1-DE_LU’ and ‘10YDK-1——–W-DE_LU’) appears once, so it is never read twice.

Args:

path (str | Path): Folder with the fetched csv’s. year (int): The year to look for. entsoe_query (str, optional): The query in the file names. Defaults to ‘crossborder_flows’.

Returns:

dict[tuple[str, str], Path]: {(from EIC code, to EIC code): file}.

pybalmorel.entsoe.find_transmission_file(path: str | pathlib.Path, year: int, zone_from: str, zone_to: str, entsoe_query: str = 'crossborder_flows') → pathlib.Path | None

The fetched file for one directed pair, whichever spelling it was saved under.

Args:

path (str | Path): Folder with the fetched csv’s. year (int): The year to look for. zone_from (str): Zone the flow originates from, in any spelling. zone_to (str): Zone the flow arrives at, in any spelling. entsoe_query (str, optional): The query in the file name. Defaults to ‘crossborder_flows’.

Returns:

Path | None: The file, or None if the pair hasn’t been fetched.

pybalmorel.entsoe.entsoe_subzones(canonical_region: str) → list[str]

The ENTSO-E bidding zones that collapse to canonical_region.

Returns multiple zones only when ENTSO-E’s resolution is finer than Balmorel’s for this region (e.g. ‘IT’ -> the 7 Italian bidding zones). Otherwise returns a single-item list of the canonical name itself.

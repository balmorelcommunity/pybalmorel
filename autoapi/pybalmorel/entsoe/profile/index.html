pybalmorel.entsoe.profile

ENTSO-E Production Profile

Hourly electricity production per production type, load, net import and day-ahead price of one or more ENTSO-E bidding zones, read from the csv’s fetched from the ENTSO-E transparency platform. Zones keep ENTSO-E’s own names (e.g. ‘DK_1’, ‘DE_LU’, ‘IT_NORD’): nothing is translated to Balmorel regions (see CONTEXT.md).

pybalmorel.entsoe.profile.read_profile(path: str | pathlib.Path, year: int, zones: str | list[str], start: str | pandas.Timestamp | None = None, end: str | pandas.Timestamp | None = None, verbose: bool = True) → EntsoeProfile

Hourly ENTSO-E production, load, net import and day-ahead price of one or more bidding zones.

Reads the ‘<year>_<zone>_<query>.csv’ files of path for the generation, load and day_ahead_prices queries, and the crossborder_flows files of the borders of the zones. Several zones are summed, except their prices, which are weighted by load. An hour missing for any of the zones is NaN in the summed generation or load. Generation and load are required for every zone; prices and flows are used if they were downloaded. With verbose, the zones, period and data found are printed.

Args:

path (str | Path): Folder with the fetched csv’s. year (int): The year the files are for. zones (str | list[str]): ENTSO-E zone(s) in any spelling, e.g. ‘DK1’, ‘DK_1’ or

‘10YDK-1——–W’. A canonical region with several bidding zones, e.g. ‘IT’, means all of them. ‘all’ means every zone in path with generation and load in the period; the other zones are left out and listed in the printout.

start (str | pd.Timestamp | None, optional): First hour to include, read as Brussels

time unless it has a time zone, e.g. ‘2023-06-26’. Defaults to None (start of the year).

end (str | pd.Timestamp | None, optional): Hour to stop before. Defaults to None (end of the year). verbose (bool, optional): Print the scope of the data. Defaults to True.

Raises:
Exception: If generation or load is missing for any of the zones, in the files

or in the period. With ‘all’, if no zone has both.

Returns:

EntsoeProfile: The hourly data, indexed by hour in Brussels time.

pybalmorel.entsoe.profile.plot_profile(path: str | pathlib.Path, year: int, zones: str | list[str], start: str | pandas.Timestamp | None = None, end: str | pandas.Timestamp | None = None, title: str | None = None) → tuple[matplotlib.figure.Figure, numpy.ndarray]

Plot the hourly ENTSO-E production, load, net import and day-ahead price of one or more bidding zones.

Production is stacked per group of production types (see production_groups), with net import on top and net export below zero, and load drawn as a line. The day-ahead price, if downloaded, is drawn in a panel below. Hours without data are left as gaps. Raises if generation or load of any of the zones is missing, and prints the zones, period and data found (see read_profile).

Args:

path (str | Path): Folder with the fetched csv’s. year (int): The year the files are for. zones (str | list[str]): ENTSO-E zone(s) in any spelling, e.g. ‘DK1’, ‘DK_1’ or

‘10YDK-1——–W’. A canonical region with several bidding zones, e.g. ‘IT’, means all of them. ‘all’ means every zone in path with generation and load.

start (str | pd.Timestamp | None, optional): First hour to plot, read as Brussels

time unless it has a time zone, e.g. ‘2023-06-26’. Defaults to None (start of the year).

end (str | pd.Timestamp | None, optional): Hour to stop before, e.g. ‘2023-07-03’.

Defaults to None (end of the year).

title (str | None, optional): Defaults to None (the zones and period).

Returns:

tuple[Figure, np.ndarray]: The figure, and its axes: production, then price if plotted.
